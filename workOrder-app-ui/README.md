# 医院后勤工单系统微信小程序

本工程使用 UniApp、Vue 2 和 uView，正式交付目标为微信小程序 `mp-weixin`。H5 仅用于开发预览，不作为生产移动端入口。已有业务页面保持现有视觉，新增页面按产品方案中的移动端视觉基线实现。

## 环境配置

构建前通过环境变量提供当前环境地址：

| 变量 | 必填 | 用途 |
|---|---|---|
| `VUE_APP_BASE_API` | 是 | 后台 HTTPS API 根地址 |
| `VUE_APP_PRIVACY_URL` | 提审前 | 隐私政策业务域名地址 |
| `VUE_APP_SERVICE_AGREEMENT_URL` | 提审前 | 用户服务协议业务域名地址 |

仓库不保存生产域名、密钥和管理员账号。未配置后台地址时，请求和上传会明确失败，不会访问公共演示系统或回退到 Mock。

## 微信小程序构建

1. 使用项目锁定的 HBuilderX 正式版打开本目录。
2. 在 `manifest.json` 中确认当前发布 AppID 由发布管理员提供。
3. 配置上述环境变量，执行“发行 → 小程序-微信”。
4. 将 `unpackage/dist/build/mp-weixin` 导入微信开发者工具。
5. 开启合法域名、HTTPS 和 ES6 校验，确认编译无阻断错误。
6. 发布体验版，在 iOS 和 Android 真机完成三角色主流程冒烟。

首次形成可发布包时，必须在发布记录中固定 HBuilderX、UniApp 编译器、微信开发者工具和基础库版本。后续构建使用相同版本，升级需单独回归。

## 平台要求

- `request`、`uploadFile`、`downloadFile` 和 `web-view` 域名必须在微信公众平台登记。
- 相机、相册和位置能力按实际调用配置隐私保护指引，不预先声明未使用能力。
- 页面禁止直接访问 `window`、`document` 和浏览器存储。
- 登录、上传、状态动作和评价失败时保留用户输入，不允许模拟成功。
- 小程序包体、分包、权限拒绝、前后台切换和扫码/分享深链必须在真机验证。

完整规则见 [微信小程序适配与发布基线](../docs/01-技术方案/微信小程序适配与发布基线.md)。

## 当前验证边界

当前仓库未配置 HBuilderX CLI 或微信 CI，需通过 HBuilderX 与微信开发者工具完成正式构建。未生成 `mp-weixin` 构建产物、未完成合法域名配置或未完成真机录屏时，不得标记小程序交付完成。
