### 移动端 UI 分类

- `01-入口与工作台`：登录、注册、首页、工作台。
- `02-报修与进度`：提交工单、我的工单、进度详情。
- `03-派单调度`：派单列表、派单详情、人员状态。
- `04-维修处理`：处理列表、处理详情、到场、评估、延期、完工提交。
- `05-完工确认与评价`：报修人确认、评价列表、评价表单、评价结果。
- `06-个人与消息`：个人中心、消息中心、头像、资料、密码、设置、帮助、关于。
- `07-通用状态`：空、加载、错误、禁用等通用状态基线。
- `08-通用内容`：网页内容和文本内容。
- `90-移动端页面总览`：移动端页面总览。

### PC 端 UI 分类

- `01-运营驾驶舱`
- `02-工单管理`
- `03-人员调度`
- `04-基础配置`
- `05-统计分析`
- `06-消息与短信`

页面原型提供 `.png` 预览图；可编辑页面同时提供 `.svg` 矢量图。
