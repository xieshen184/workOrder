# M1-B03 取消、确认、退回与评价节点验收清单

## 交付范围

本节点完成报修人侧业务闭环，覆盖待派单取消、完工确认、退回返工、评价提交和评价查询。延期、通知、自动关闭和运营统计属于后续节点，不纳入本节点完成判定。

## 接口清单

| 方法 | 路径 | 权限 | 完成条件 |
|---|---|---|---|
| POST | `/workorder/orders/{id}/cancel` | `workorder:order:cancel` | 待派单工单进入已取消，仅创建人或授权调度管理员可以执行 |
| POST | `/workorder/orders/{id}/confirm` | `workorder:order:confirm` | 待确认工单进入已完成，仅工单创建人可以执行 |
| POST | `/workorder/orders/{id}/return` | `workorder:order:return` | 待确认工单退回处理中，原因必填，既有完工记录保持不变 |
| POST | `/workorder/orders/{id}/evaluation` | `workorder:evaluation:add` | 已完成工单写入唯一评价并进入已关闭，仅工单创建人可以执行 |
| GET | `/workorder/orders/{id}/evaluation` | `workorder:evaluation:query` | 在工单数据范围内返回评价只读信息，不存在时返回明确结果 |

所有状态写接口必须携带 `Idempotency-Key`，请求体必须携带客户端最后一次读取到的 `version`。成功响应返回最新 `status`、`version` 和 `idempotentReplay`。

## 状态链路

| 当前状态 | 动作 | 目标状态 | 执行角色 |
|---|---|---|---|
| `WAIT_ASSIGN` | `CANCEL` | `CANCELLED` | 工单创建人或授权调度管理员 |
| `WAIT_CONFIRM` | `RETURN` | `PROCESSING` | 工单创建人或授权调度管理员 |
| `WAIT_CONFIRM` | `CONFIRM` | `COMPLETED` | 工单创建人 |
| `COMPLETED` | `EVALUATE` | `CLOSED` | 工单创建人 |

## 数据一致性

- 状态更新必须同时匹配工单 ID、当前状态和版本号；成功后版本号递增。
- 状态冲突或旧版本请求不得覆盖新数据，客户端收到冲突后重新加载详情。
- 同一用户、同一动作和同一幂等键重试只产生一次状态变化和一条动作日志。
- 退回原因必须进入时间线，首次及后续完工记录不得被更新或删除。
- 每张工单最多存在一条评价，应用校验和数据库唯一索引共同防止重复评价。
- 评价分数必须为 1–5，评价内容最长 500 字；分项评分未填写时保持为空。
- 评价写入、工单关闭和动作日志必须位于同一数据库事务。
- 越权、非法状态、重复评价和版本冲突不得产生部分数据。

## PC 管理端

- 仅当详情 `allowedActions` 包含 `RETURN` 且用户具有对应权限时显示退回入口。
- 退回原因必填，提交前二次确认，提交期间禁止重复点击。
- 并发冲突时明确提示工单已变化，并重新加载最新详情和列表。
- 已完成或已关闭工单展示评价只读信息；管理员不能代替报修人确认或评价。
- 切换工单时清空上一张工单的评价数据和错误状态。

## 微信小程序

- 工单详情的取消、确认、退回和评价入口完全由 `allowedActions` 控制。
- 待确认页面真实展示处理结果和完工附件，确认与退回均需要二次确认。
- 退回原因必填；失败后保留填写内容，成功后返回最新工单状态。
- 待评价和已评价列表使用真实分页数据，分别维护加载、错误、空数据和是否还有更多状态。
- 评价星级必填，提交期间禁止重复点击；评价成功后进入只读详情并刷新列表。
- 每次新的用户操作生成新幂等键；网络失败重试复用原幂等键，修改请求内容后生成新键。
- 页面保持现有色彩、卡片、间距和导航样式，不修改既有视觉风格。

## 验收场景

| 编号 | 检查项 | 通过标准 |
|---|---|---|
| B03-01 | 正常闭环 | 待确认工单确认后进入已完成，评价后进入已关闭，评价详情可查询 |
| B03-02 | 退回闭环 | 待确认工单填写原因退回处理中，再次完工和确认成功，首次完工记录保留 |
| B03-03 | 待派单取消 | 创建人或授权管理员可取消待派单工单，派单后不能取消 |
| B03-04 | 评价唯一 | 每张工单只能评价一次，同一幂等请求可重放，不同请求不能新增第二条评价 |
| B03-05 | 角色权限 | 非创建人不能确认或评价；无权限用户不能退回、取消或查看评价 |
| B03-06 | 非法状态 | 在错误状态执行动作被拒绝，工单、评价和日志均不发生变化 |
| B03-07 | 并发冲突 | 两个请求使用同一旧版本提交时最多一个成功，失败方刷新最新状态 |
| B03-08 | PC 退回 | 管理端仅在允许时退回，原因进入时间线，评价保持只读 |
| B03-09 | 小程序确认 | 报修人可查看完工证据并完成确认或退回，错误和冲突可恢复 |
| B03-10 | 小程序评价 | 待评价与已评价列表、评价表单和评价详情使用真实接口完成闭环 |
