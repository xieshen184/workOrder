# M1-B04 权限、幂等、并发、审计与核心 Mock 清理节点验收清单

## 交付范围

本节点完成第一版核心链路的安全与一致性收口，并将微信小程序派单页面、派单详情和首页统计从业务模拟数据切换为真实接口。延期、SLA、消息通知、运营统计和监控平台属于后续节点，不纳入本节点完成判定。

## 角色与权限

| 角色 | 数据范围 | 允许能力 | 禁止能力 |
|---|---|---|---|
| 报修人 | 本人创建的工单 | 创建、查询、取消、退回、确认、评价、本人附件上传与下载 | 派单、改派、维修处理、查看他人工单 |
| 维修人员 | 当前分配给本人或本人参与处理的工单 | 查询任务、接单、到场、评估、更新进度、完工、过程附件上传与下载 | 派单、改派、确认、评价、处理他人工单 |
| 调度管理员 | 授权部门范围内的工单 | 列表、详情、取消、退回、派单、改派、维修人员查询、分类维护、评价只读查询 | 代替报修人确认或评价、越过部门范围访问数据 |

接口权限、数据范围和领域动作策略必须同时生效。仅拥有菜单按钮权限但不满足工单归属、当前处理人、部门范围或状态条件时，服务端仍须拒绝操作。

## 一致性与审计要求

- 所有状态写接口必须携带 `Idempotency-Key` 和客户端最后读取到的 `version`。
- 同一用户、同一动作、同一幂等键和同一请求内容重试时返回首次结果，不得重复变更状态或写入业务记录。
- 幂等键用于不同工单、版本或请求内容时必须返回冲突，不得复用首次结果。
- 权限和数据可见性校验必须先于幂等结果读取，避免通过幂等键获取无权访问的工单结果。
- 命令执行时必须锁定当前工单，并以工单 ID、源状态和版本号作为最终更新条件。
- 两个请求使用同一旧版本并发提交时最多一个成功；失败请求不得覆盖新状态。
- 工单状态、派单记录、过程记录、附件绑定、评价和动作日志必须在同一事务中提交或回滚。
- 动作日志必须记录工单、操作人、动作、前后状态、业务时间、幂等键和可重放结果。
- 系统操作日志继续由控制器日志注解记录，业务动作日志用于还原工单时间线，两者职责不得混用。

## 微信小程序派单

- 派单列表使用调度管理员真实分页接口，不保留硬编码工单、示例图片地址或延时模拟。
- “申请中”展示待派单工单；“已派发”展示已分配、等待维修人员接单的工单，接单后由维修处理入口继续承接。
- 列表支持下拉刷新、加载更多、空数据、错误提示和重新加载。
- 维修人员候选项来自真实接口，页面展示姓名、部门、工作状态和当前负载。
- 详情以服务端 `allowedActions` 控制派单或改派入口，不根据本地状态绕过服务端授权。
- 派单和改派提交当前 `version`；网络失败重试复用原幂等键，选择人员、说明或版本变化后生成新键。
- 收到并发冲突后提示工单已变化，清除旧提交状态并重新加载详情。
- 私有附件只通过现有鉴权下载或预览能力访问，不拼接对象存储地址或公共示例地址。
- 页面保持现有色彩、卡片、间距和导航结构，不修改既有视觉风格。

## 微信小程序首页

- 首页统计根据当前用户权限选择调度管理员、维修人员或报修人真实数据源。
- 首页只展示后端可以准确提供的实时工单总量和状态分布，不使用固定数字、随机趋势或模拟成功结果。
- 不具备某个功能权限时隐藏对应入口；服务端继续执行最终权限校验。
- 多个状态统计请求独立降级，单项失败不得将其他已成功统计覆盖为模拟值。
- 页面重新显示或用户主动刷新时重新读取数据，加载、失败和空数据状态清晰可见。

## 菜单与初始化脚本

- 三个工单角色按 `role_key` 幂等创建，重复执行脚本不得产生重复角色或重复授权关系。
- 报修人、维修人员和调度管理员仅获得本角色完成第一版流程所需的最小按钮权限。
- 调度管理员的部门数据范围必须在生产初始化后配置授权部门，未配置前不得按全量数据处理。
- 菜单权限字符串必须与控制器权限注解逐项一致，不允许脚本已授权但接口未校验，或接口要求权限但角色未获得。

## 验收场景

| 编号 | 检查项 | 通过标准 |
|---|---|---|
| B04-01 | 最小角色授权 | 三角色只获得完成自身流程所需权限，跨角色动作被拒绝 |
| B04-02 | 数据范围 | 本人、当前处理人和授权部门范围分别生效，详情与列表口径一致 |
| B04-03 | 可见性优先 | 无权用户即使持有有效幂等键也不能获取原命令结果 |
| B04-04 | 同键重试 | 相同请求重试返回首次结果，不重复写入状态、记录、附件绑定或日志 |
| B04-05 | 键冲突 | 相同幂等键用于不同请求时返回冲突，原结果保持不变 |
| B04-06 | 版本并发 | 两个旧版本请求最多一个成功，失败请求刷新后才能再次提交 |
| B04-07 | 事务回滚 | 任一业务记录或审计日志写入失败时，本次命令不产生部分数据 |
| B04-08 | 审计完整 | 时间线可以还原操作人、动作、时间、前后状态和操作说明 |
| B04-09 | 移动派单 | 列表、详情、维修人员、派单和改派均使用真实接口，失败可恢复 |
| B04-10 | 首页真实统计 | 三角色首页按权限读取真实数据，不出现固定统计或随机趋势 |
| B04-11 | 核心 Mock 扫描 | 移动端业务代码不存在硬编码工单、模拟接口、示例图片地址和随机业务统计 |
| B04-12 | 回归构建 | 后端测试与打包、PC 生产构建、小程序静态校验全部通过 |
