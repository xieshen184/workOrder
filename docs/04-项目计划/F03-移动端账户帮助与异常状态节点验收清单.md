# F03 移动端账户、帮助与异常状态节点验收清单

## 交付范围

本节点完成移动端 M11、M21、M23–M31 的工程接入，包括个人中心、头像、个人信息、资料编辑、修改密码、应用设置、常见问题、关于、受信网页、结构化文本及通用异常状态。现有页面沿用原有视觉基线，缺失状态补齐为同一套组件和交互规则。

本节点完成代码开发与自动化验证，不包含微信开发者工具构建、体验版上传、真机测试、HTTPS 业务域名配置和三角色联调；这些事项继续保留到统一联调阶段。

## 账户与密码规则

- 资料接口仍使用当前登录用户身份，客户端不能指定其他用户编号。
- 昵称、手机号和性别必填；手机号、邮箱、长度和脚本字符由服务端再次校验。
- 手机号在个人信息页默认脱敏，岗位、角色、组织、账号和创建时间只读。
- 新密码为 8–20 位，必须同时包含英文字母和数字，不得与旧密码相同。
- 旧密码错误次数使用独立 Redis 键统计，不影响正常登录失败次数；达到配置阈值后返回剩余等待时间。
- 密码修改成功后服务端删除当前令牌，移动端无论服务端注销接口是否可达都清理本机身份。
- 头像只接受后端允许的图片格式和大小；用户取消、读取失败、裁剪失败或上传失败时不覆盖原头像。

## 内容与缓存安全

- 帮助页只持有内容编号，标题、段落和步骤统一从内容注册表读取。
- 文本页 query 只接收内容编号；不存在的编号进入明确错误态。
- 网页页 query 只接收受信资源键；URL 由注册表解析，并校验 HTTPS、主机名和配置白名单。
- 在线协议未配置或加载失败时进入内置纯文本，不使用任意 URL 回退。
- 缓存管理器只遍历明确登记的非业务键，不调用 `clearStorageSync` 或用户存储全量清理。
- 令牌、用户资料、业务数据和名称中包含 token、draft、business 的键均受保护。

## 状态控制

| 状态 | 页面反馈 | 可执行动作 |
|---|---|---|
| 加载中 | 显示加载反馈并阻止重复请求 | 等待完成 |
| 无内容 | 说明当前没有内容及原因 | 由业务页提供唯一主动作 |
| 搜索无结果 | 说明关键词未匹配 | 清除搜索 |
| 加载失败 | 保留已有结构或输入 | 重新加载 |
| 网络不可用 | 明确提示检查网络 | 重新检测网络 |
| 无权限 | 明确说明当前账号无权访问 | 返回可访问页面 |
| 功能禁用 | 说明功能尚未开放 | 返回上一页 |

## 服务端保护

- 修改资料使用服务端当前登录用户作为更新对象，只复制允许编辑的四个字段。
- 修改密码强度由独立策略类校验，客户端校验不能绕过服务端规则。
- 旧密码失败次数使用 Redis 原子递增，首次失败建立锁定窗口。
- 修改密码成功后立即删除当前会话令牌，不继续刷新旧令牌。
- 资料更新、头像上传和密码更新继续写入若依操作日志。
