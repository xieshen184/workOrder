# UX 用户体验流程图

## 1. 角色与核心闭环

```mermaid
flowchart LR
    U["报修人"] --> A["提交工单"]
    A --> D["调度员派单"]
    D --> E["维修人员接单"]
    E --> F["到场打卡"]
    F --> G["故障评估"]
    G --> H["维修与进度更新"]
    H --> I["提交完工"]
    I --> J{"报修人核验"}
    J -->|"通过"| K["确认完成"]
    J -->|"不通过"| H
    K --> L["评价 / 自动关闭"]
```

## 3. 维修人员旅程

```mermaid
flowchart TD
    A["收到派单通知"] --> B["查看工单详情"]

    C -->|"可以"| D["接单"]

    G --> H["开始处理"]

```

## 7. 异常与反馈闭环

```mermaid
flowchart LR
    ACTION["用户动作"] --> LOADING["按钮禁用 + 加载"]
    LOADING --> RESULT{"请求结果"}
    RESULT -->|"成功"| SUCCESS["成功提示 + 局部刷新"]
    RESULT -->|"校验失败"| VALIDATE["字段下方说明如何修复"]
    RESULT -->|"版本冲突"| CONFLICT["提示状态已变化 + 刷新详情"]
    RESULT -->|"网络失败"| RETRY["保留输入 + 提供重试"]
    SUCCESS --> NEXT["进入下一状态或返回列表"]
    VALIDATE --> ACTION
    CONFLICT --> NEXT
    RETRY --> ACTION
```
